# 🎨 Online Paint App

Интерактивное веб-приложение для рисования в режиме онлайн. Проект построен на архитектуре Fullstack (Client-Server) с использованием современных JavaScript-технологий.

## 🚀 Технологический стек

**Клиент (Client):**
* **React** — декларативный UI-фреймворк.
* **Vite** — быстрый инструмент сборки проекта.
* **HTML5 Canvas API** — основа для реализации холста и инструментов рисования.
* **JavaScript (ES6+)** — логика клиентской части.

**Сервер (Server):**
* **Node.js** — программная платформа для бэкенда.
* **Express** — минималистичный веб-фреймворк для обработки API-запросов.

---

## ✨ Функционал приложения

* **Инструменты рисования:** кисть, ластик, геометрические фигуры (линии, прямоугольники, круги).
* **Кастомизация:** настройка цвета линий, цвета заливки и толщины кисти.
* **Управление холстом:** очистка экрана, сохранение получившегося рисунка на компьютер.
* **Fullstack-архитектура:** раздельное управление интерфейсом и серверной логикой для масштабируемости.

## 🛠️ Инструкция по локальному запуску

Для работы проекта вам понадобятся установленные **Node.js** (версии 18+) и **npm**.

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd имя-репозитория
```

### 2. Настройка и запуск Сервера (Backend)
```bash
cd server
npm install
npm start
```
*Сервер запустится на порту по умолчанию (например, `http://localhost:5000`).*

### 3. Настройка и запуск Клиента (Frontend)
Откройте **новое окно терминала** в корне проекта и выполните:
```bash
cd client
npm install
npm run dev
```
*Приложение откроется локально в браузере (обычно по адресу `http://localhost:5173`).*
